# Brigadier Implementation
A simple example implementation of mojang's brigadier library.

## Running
_(all commands executed from project root directory)_  
_You of course need java_

Build with `./gradlew build`

The jar will be in `build/libs/brigadier-impl-1.0-SNAPSHOT.jar`, you can run it with `java -jar build/libs/brigadier-impl-1.0-SNAPSHOT.jar`
